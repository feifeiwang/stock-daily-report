## 一、经验库 `预测经验跟踪.xlsx`（GitHub，10 列）

Sheet1「每日预测与验证」，一行一天：

| 列 | 字段 | 说明 |
|---|---|---|
| A | 日期 | 预测发布日，如 2026-10-21 |
| B | 上证指数预测 | 方向 + 收盘区间（简写，如 `低开震荡 3688~3723`） |
| C | 创业板指预测 | 同上 |
| D | 恒生指数预测 | 同上 |
| E | 恒生科技预测 | 同上（每日必报） |
| F | 大盘判定 | 准确 / 部分准确 / 不准确 / 待验证 |
| G | 板块判定 | 同上 |
| H | 个股判定 | 同上 |
| I | 综合得分 | 准确=1、部分准确=0.5、不准确=0，6 项制（大盘4+板块1+个股1） |
| J | 经验与失败原因 | **必读列**。上一日失败原因归因 + 本期调整动作；无失败写「—」 |

Sheet2「说明」：用途、列说明、累计准确率口径、硬规则摘要、累计失败原因清单、来源与免责声明。

### 判定口径（6 项制）

- 大盘 4 项（沪深创业板/恒指/恒科）逐项判：方向一致且关键点位命中=准确；方向一致但幅度或点位有偏=部分准确；方向错=不准确。
- 板块 1 项、个股 1 项同口径。
- 综合得分 = 各项得分之和（满分 6）。
- 累计准确率 = 总得分 / 总项数。

### 每期流程

1. **先读**：下载/读取经验库，重点读 J 列（失败原因）与 F~I 列（历史判定），在 Step 1 采集前形成"本期调整要点"，写进 MD 的「预测修订与经验」小节。
2. **回填上一日**：把上一日 F~H 判定与 J 列失败原因补齐（若为空）。
3. **追加本期行**：B~E 写当日四指数预测，F~H 写"待验证"，I 写预估得分，J 写本期依据与针对性调整。
4. 更新 Sheet2 累计准确率与失败原因清单。

**同对象预测合并**：A 股休市导致的连续多日预测若针对同一对象（如 10-18/10-19 与 10-17），只保留一行并在 J 列注明合并说明。

## 二、全量跟踪 `每日行情预测准确率跟踪.xlsx`（本地）

### Sheet1「每日预测跟踪」——一行对应一个预测日

| 列 | 字段 | 说明 |
|---|---|---|
| A | 日期 | 预测发布日 |
| B | 预测发布时间 | 如 2026-10-21 07:30 |
| C | 上证指数预测 | 方向+收盘区间+波动范围+关键点位 |
| D | 创业板指预测 | 同上 |
| E | 恒生指数预测 | 同上 |
| F | 恒生科技预测 | **每日必报项** |
| G | 板块预测 | 看多/看空方向板块 |
| H | 个股预测 | 关注/回避名单（含代码） |
| I | 验证日期 | 次日收盘后回填 |
| J-Q | 实际收盘/涨跌幅 ×4 | 次日回填 |
| R | 大盘预测准确性 | 准确 / 部分准确 / 不准确 / 待验证 |
| S | 板块预测准确性 | 同上 |
| T | 个股预测准确性 | 同上 |
| U | 备注 | 逐项兑现情况详述 + 修订留痕 |

### Sheet2「说明」——使用说明、判定标准与免责声明

### 防重与修订纪律

1. **先检查**：打开 Excel 看是否已有当天日期的行；有则不新增（"已做完不重做"）。
2. 当天写新行，实际结果列留空、准确性标"待验证"。
3. **次日收盘后**回填实际数据与判定（口径同经验库 6 项制）。
4. 用 openpyxl 操作；重复行用 `delete_rows` 去重，保持"一行对应一天"。
5. **修订留痕**：区间被后续修订（如按新规收窄）时，**不覆盖原行**，在 U 列追加 `【日期 时间 修订】按<规则>收窄：…；原宽区间版作废`，并在经验库 J 列同步说明。
