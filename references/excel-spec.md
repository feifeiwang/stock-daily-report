# 股票预测总表规范

## 一、位置与职责

| 文件 | 位置 | 职责 |
|---|---|---|
| `股票预测总表.xlsx` | `股票预测/股票预测总表.xlsx` | 每个执行日追加一行，简记当日开盘预测、上一交易日结果、关键依据和四个产物路径 |
| 旧版 `预测经验跟踪.xlsx` | 仓库根（只读兼容） | 历史六项制经验库；新数据迁移稳定后可停止读取 |

> 用户2026-10-26定稿：总表放在GitHub仓库的“股票预测”文件夹中；每日产物按 `YYYYMM` 月份目录归档。

## 二、每日总览字段

Sheet「每日总览」一行对应一个执行日：

| 列 | 字段 | 说明 |
|---|---|---|
| A | 序号 | 自增整数 |
| B | 日期 | 预测发布日，格式 `YYYY-MM-DD` |
| C | 上证开盘预测 | 方向 + 开盘区间 |
| D | 创业板开盘预测 | 方向 + 开盘区间 |
| E | 恒指开盘预测 | 方向 + 开盘区间 |
| F | 恒科开盘预测 | 方向 + 开盘区间 |
| G | 上一交易日预测结果 | 开盘命中数、收盘命中数、六项制得分的简短结论 |
| H | 今日关键依据 | 只写3~5个最重要变量，不塞入整篇报告 |
| I | 当日MD | `YYYYMM/YYYY-MM-DD.md` 相对路径 |
| J | 图1复盘 | `YYYYMM/YYYY-MM-DD_1.jpg` 相对路径 |
| K | 图2要闻 | `YYYYMM/YYYY-MM-DD_2.jpg` 相对路径 |
| L | 图3预测 | `YYYYMM/YYYY-MM-DD_3.jpg` 相对路径 |
| M | 状态 | `待验证` 或验证摘要 |

Sheet「说明」记录交易日跳过规则、字段口径、归档结构和免责声明。

## 三、交易日与防重复

1. 仅当上证与中国香港股市同日均休市时跳过，不新增Excel行。
2. 执行前先按日期查重；若B列已有当天日期，视为已生成，不重复追加。
3. 月份目录采用 `YYYYMM`，例如 `202610`；不存在才创建。
4. 每期目录只归档1个MD和3张JPG，不归档PNG、HTML和长图。

## 四、验证口径

### 4.1 开盘判定

- 实际开盘方向一致且落入预测开盘区间：准确。
- 方向一致但超出区间：部分准确。
- 方向相反：不准确。

### 4.2 收盘判定

- 方向一致且实际收盘落入预测收盘区间：准确。
- 方向一致但点位偏离：部分准确。
- 方向相反：不准确。

### 4.3 六项制兼容评分

- 大盘4项：上证、创业板、恒指、恒科。
- 板块1项、个股1项。
- 准确=1，部分准确=0.5，不准确=0；满分6。
- 累计准确率 = 所有已完结预测日的六项得分之和 /（已完结预测日数量 × 6）；每新增一个完成复盘的预测日，分母增加6。例如18/30加上新一期1/6后为19/36。
- 开盘与收盘必须分开写结论，不得用开盘命中替代收盘命中。

### 4.4 机械判定（A41，2026-11-07 统一，务必照此执行）

> 历史上「方向对但出区间」有时记 0、有时记 0.5，属口径漂移。此后统一由
> `scripts/finalize_prev_day.py` 机械判定，不再手工给分：

| 情形 | 单项得分 |
|---|---|
| 实际值落在预测区间内（含端点） | **1.0** |
| 预测方向与实际方向一致，但落在区间外 | **0.5** |
| 预测方向与实际方向相反 | **0** |

- 预测方向来自值表 `*_pred_sign(-1/0/1)`（由预测区间相对昨收的位置判定）；实际方向 = `sign(实际值 − 昨收)`。
- 综合 /6 = 开盘总分÷2 + 收盘总分÷2 + 板块(0/0.5/1) + 个股(0/0.5/1)。

### 4.5 G / M 列语义（A34/A42，休市日回填红线）

| 列 | 语义 | 谁写 |
|---|---|---|
| **G 列「上一交易日预测结果」** | **该行自己的上一交易日**那一期预测的结果（如 11-06 行的 G 列写 `11-05：…`） | 常规日由 `append_row.py` 的 `XLSX_PREV_RESULT` 写入新行；**休市日回填绝不改 G 列** |
| **M 列「状态」** | **该行自己**的验证状态：`待验证` → `已验证：…` | 常规日 `--prev-result` 只回填上一行 M 列；休市日由 `finalize_prev_day.py` 回填最后一行 M 列 + 绿底 `FFE2F0D9` |

> 休市日回填只改 **M 列**。旧版 SKILL.md「休市日标准动作」曾写「G 列写 `MM-DD：…`」，
> 那是 A34 之前的过时口径，照做会把 G 列覆写成该行自身结果（11-04 踩过），已修正。

## 五、每期更新顺序

1. 先读最近一行的“上一交易日预测结果”和“今日关键依据”。
2. 用实际开盘、收盘、板块和个股表现验证上一期。
3. 在当日新行的G列写上一期结果，在C~F列写当日开盘预测。
4. I~L列写相对路径，M列写“待验证”。
5. 下一次执行时回填上一期状态；不得覆盖历史预测文本。

## 六、格式要求

- 表头固定、开启筛选；横向较宽时冻结日期前两列。
- 日期使用真正的日期类型，不写成随意文本。
- 长文本列自动换行；每格保持短句。
- 涨跌颜色遵循中国市场习惯：涨红、跌绿。
- 工作簿元数据按平台要求写入AI生成内容标识。
