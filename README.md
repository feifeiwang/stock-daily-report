# stock-daily-report · 每日股市开盘预测 Skill

每天早晨自动检查上证与中国香港股市交易日；只要任一市场开市，就生成：**1份MD日报 + 3张1080×1920竖版JPG + 1行累计Excel记录**。两地同日均休市时跳过。

本仓库既是一个 Agent Skill（`SKILL.md` + `references/`），也可以把 `scripts/` 当独立的图片生成工具使用。

## 产出物

累计总表固定为：

- `股票预测/股票预测总表.xlsx`

每日产物按六位月份目录归档，例如 `股票预测/202610/`：

| 文件 | 内容 |
|---|---|
| `{日期}.md` | 交易日检查、上一交易日复盘、盘前要闻、四指数开盘预测、收盘/日内区间、板块个股与风险提示 |
| `{日期}_1.jpg` | 图1：上一开盘日开盘/收盘预测复盘 + 累计准确率 |
| `{日期}_2.jpg` | 图2：盘前关键要闻 |
| `{日期}_3.jpg` | 图3：今日开盘区间优先的预测卡 + 个股观察 |

旧版 `YYYY/MM/` 与根目录 `预测经验跟踪.xlsx` 作为历史兼容数据保留，不再新增。

## 每日流程

```text
0 交易日检查   → 上证与中国香港股市同日均休市才跳过
1 防重复       → 查当日MD与总表日期，已存在不重做
2 读历史       → 读总表最近结果与失败原因
3 采集核实     → 多源核验前一交易日收盘、盘前期指、商品、资金和要闻
4 预测         → 开盘方向和区间优先；附收盘/日内区间
5 复盘         → 开盘与收盘分开判定，不能以开盘命中替代全天命中
6 写MD         → 按md-template.md生成
7 更新Excel    → 追加当日一行，写上一交易日结果与四个产物路径
8 三张图       → 只改gen3_images.py顶部D字典，运行并测高
9 转JPG        → 仓库不保留当日PNG
10 提交GitHub  → 正常git提交推送，远程回验
```

## 预测硬规则

1. 必报上证指数、创业板指、恒生指数、恒生科技指数。
2. 每项先给开盘方向、开盘数值区间、相对昨收百分比与置信度。
3. 收盘区间宽度不超过昨收1%；日内区间宽度不超过1.5个百分点且包含收盘区间。
4. 图3轨道统一为昨收±2%，百分比由数值实时计算，禁止手填。
5. 美股只作背景，不给美股操作建议；板块与个股覆盖中国香港、上证和创业板。
6. 数字必须可溯源；盘前数据冲突时采取保守区间并说明假设。
7. 图片一律JPG；涨红、跌绿；关键数字用白色或金色。
8. 每张图底部固定“AI预测，仅供参考，不构成投资建议”。

## 模板与经验沉淀

- 每天只更新 `scripts/gen3_images.py` 顶部 `D` 数据区，卡片函数、轨道、圆环与CSS保持固化。
- 每次发生数据源、日历、GitHub推送、截图或预测验证问题，都把“现象—原因—解决方法”追加到 `references/pitfalls.md`。
- `references/md-template.md` 与 `references/excel-spec.md` 是后续自动化的固定内容模板。

## 凭据安全

GitHub Token只通过环境变量使用，禁止写入仓库、脚本、日志、MD、Excel或远程URL。推送完成后删除仓库外的临时凭据文件。
