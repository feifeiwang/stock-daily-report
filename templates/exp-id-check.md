# 经验编号核查骨架（A60）

> 用法：`cp templates/exp-id-check.md work/{日期}/exp-id.md` → **只改数字与文字**。
> 时机：**每次准备固化新经验 / 写复盘值表 ROOT_CAUSE / 更新 runbook 坑表之前**，必跑一次
> `python3 scripts/next_exp_id.py --repo <仓库绝对路径>`。
> 背景：A49 的编号纪律只管「同一次运行里多条新经验」，没管「上一流程（尤其 14:15 收盘前预测）
> 已在运行日志里预留了 A 编号」。11-12 14:15 日志预留 A57/A58，11-13 早报初稿未核查就把
> 「A50 夜盘零跟随」也记成 A57，险些同号异物。**早报流程与收盘前流程共用同一编号空间。**

## 一、核查命令（A35：绝对路径）

```bash
python3 scripts/next_exp_id.py --repo /tmp/sdr
python3 scripts/next_exp_id.py --repo /tmp/sdr --json   # 供脚本消费
```
