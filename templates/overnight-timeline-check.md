# 隔夜时序对齐核查骨架（A56）

> **用法**：每日采集「隔夜外围」时，`cp templates/overnight-timeline-check.md work/{日期}/overnight-timeline.md`，**只改数字和文字**即可完成裁决，把结论写进 MD「数据来源」与 `XLSX_BASIS`。
>
> **根因（A56）**：早报（尤其微信「国内资讯/财经早餐」类稿件）会把**两组方向相反的美股收盘数据写在同一篇里**——
> 一组是「解释**昨日** A股为何低开/高开」的**回顾性旧隔夜**（美东 T-2 或更早），
> 另一组才是「**今日**盘前定价」的**新隔夜**（美东 T-1）。
> 中文发稿日 ≠ 美东交易日；「前一夜」「受隔夜影响」等字样指向的是该稿**复盘的那个交易日**，不是今天。
> 若误用旧隔夜给今日四指数定价，方向会整体判反（2026-11-12 首踩）。

## 2. 四步裁决（ novelty：与 A49 三重校验 + A51 方向佐证叠加使用）

1. **事件时序自洽**：新隔夜必须能解释「盘后才发生的事件」。例：CoreWeave 财报 `{}` 盘后、英伟达「两日累跌后反弹」、美债退伍军人节休市、CPI 公布日 `{}` —— 逐条对齐美东日期，能对上的那组才是新隔夜。
2. **精确点位 + 涨跌幅自洽**（A49）：`收盘 / 前收 - 1` 与稿中涨跌幅是否一致；孤证且量级偏离（>1%）即弃用。
3. **≥2（最好 ≥4）权威源交叉**（A51）：雅虎财经 / 新华社 / 财联社 / 中央社 / 东财 / 实时行情面板，同组数据须多源一致。
4. **方向佐证**（A51）：若两组符号相反，用对应 ETF（费半→SOXQ/SOXX）+ 成分股结构（英伟达/存储链/光通信）+ 亚太当日表现交叉定方向。
