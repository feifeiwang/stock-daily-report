# 行情数据互斥裁决骨架（A49 / A51 / A51附）

> **用法**：当同日采集出现两套及以上互斥的「收盘 / 开盘 / 成交额 / 涨跌家数 / 涨跌幅方向」数据时，
> `cp templates/data-conflict-triage.md work/{日期}/data-conflict.md`，**只改数字和文字**即可完成裁决记录。
> 不联网、不重搜，只对手上已有来源做校验；裁决结论同步写进当日 MD「数据来源/假设」、
> runbook 运行日志、`XLSX_BASIS` 末尾一句。
>
> **触发场景**：
> - **A16 年份污染**：搜索返回旧年份同月日数据。
> - **A49 量级互斥**：同一天、同一市场多份早报给出互斥点位 / 成交额 / 涨跌家数，尤其带「走势预判」的营销号稿常整段沿用旧稿。
> - **A51 方向互斥**：同一晚同一指数出现**涨跌幅符号相反**的两个口径（如费半 `-0.35%` vs `+1.4%`）。
> - **A51附 孤证来源恢复**：曾被判污染弃用的来源，本期给出与权威源一致的正确数据。

## 裁决四步（缺一不可，顺序执行）

1. **精确 OHLC**：`basic_info` 四指数行情表给出开 / 收 / 高 / 低精确值（A股 000001.SZ / 399006.SZ，港股 HSI.HK / HSTECH.HK）。
2. **涨跌幅自洽**：逐项算 `收盘 / 昨收 − 1 = 收盘涨跌幅`，误差 <0.01pct；孤证若与标注涨跌幅不符即出局。
3. **≥2 权威源交叉**：次日早报 / 新华社港股通稿 / 主流财经媒体行情页 / 交易所口径，列出来源数量与链接。
4. **方向佐证（A51 新增，仅方向互斥时执行）**：用**对应 ETF**（费半 → SOXQ / SOXX，纳指 → QQQ，恒科 → 恒生科技 ETF）与**成分股结构**（龙头涨跌分布、板块涨跌榜）判断方向；采用与 ETF 及成分结构自洽者，孤证方向相反即弃用。禁止「取平均」或「凭感觉选一个」。

> 四项全通过 → **采用**；任一为孤证且量级偏离（点位差 >1%、成交额差 >20%、涨跌家数方向相反）或方向相反 → **弃用并记录**。
> 禁止让孤证单独定锚（A36 定锚基准必须来自采用值）。

## 来源处置（A51附）

- **弃用是对「单条数据」的裁决，不是对「来源」的永久评级**。
- 同一来源不同日可一份污染一份正常（同花顺 11-10 污染 / 11-11 正常）。
- 每期对每条数据**重新独立跑四步**，不因单次污染永久拉黑来源，也不因一次正常放松校验。
- 来源信誉与数据正确性分开记：可记「某源近 N 期出现 M 次异常」，但不得据此跳过校验。
