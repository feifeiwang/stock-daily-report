# 每日数据模板字段说明（templates/day_template.json）

> 每天只改这一个 JSON。改完直接 `python3 scripts/build_charts.py --data day.json --out out/`。
> 下面的字段名就是 JSON 的键；**以 `_` 开头的键是分组注释，脚本会忽略**。

## 0. 全局（图1 表头 / 文件命名）

| 键 | 示例 | 说明 |
|---|---|---|
| `DATE` | `2026-10-27` | 今天；决定文件名与月份目录 |
| `PREV_MD` | `10·26` | 图1 大标题里的上一开盘日（用 `·`） |
| `PREV_DATE_WEEK` | `2026-10-26 周一` | 图1 副标题；**中性措辞**，禁写休市/首开 |
| `ACC_PCT` | `58.3` | 累计准确率数字（圆环用），无百分号 |
| `ACC_SCORE` | `21 / 36` | 累计得分，六项制 |
| `REV_SUMMARY_LINE1` | `本期开盘 3/4 命中 · 收盘 2/4 命中 · 板块 0.5 · 个股 0.5` | 圆环右侧第一行 |
| `REV_SUMMARY_LINE2` | `开盘与收盘分开验证，避免以开盘命中替代全天` | 第二行 |

## 1. 图1 · 四指数实际收盘

`{指数}` ∈ `SZ`（上证）、`CYB`（创业板）、`HSI`（恒指）、`HSTECH`（恒生科技）

| 键 | 示例 | 说明 |
|---|---|---|
| `{指数}_ACTUAL` | `3690.48` | 上一开盘日实际收盘点位（只写数字） |
| `{指数}_PCT` | `0.89` / `-0.50` | 涨跌幅，正数涨、负数跌；**红涨绿跌与 ▲▼ 由脚本自动决定** |
| `{指数}_PREV_PRED` | `低开下探·弱势企稳` | 上一期对这一指数的预测要点 |
| `{指数}_TAG` | `tag-ok` / `tag-half` / `tag-bad` | 判定标签配色 |
| `{指数}_TAG_TXT` | `✓ 准确` / `◐ 开准收错` / `✗ 不准确` | 标签文字 |
| `{指数}_REV_NOTE` | `实际低开0.94%命中；午后深V收3690.48，突破区间上限` | 复盘一句话 |

## 2. 图1 · 板块 / 个股判定

| 键 | 示例 |
|---|---|
| `SECTOR_TAG` / `SECTOR_JUDGE` | `tag-half` / `部分准确` |
| `STOCK_TAG` / `STOCK_JUDGE` | `tag-bad` / `不准确` |
| `EXTRA_NOTE` | `机器人兑现但半导体午后反攻，红利防御判断偏差，综合1/6` |

## 3. 图1 · 上一开盘日速览（固定 4 条）

`BRIEF1_T` + `BRIEF1_D` … `BRIEF4_T` + `BRIEF4_D`。每条 ≤ 26 字（含标点），超了会溢出页脚。

## 4. 图2 · 要闻（固定 6 条）

| 键 | 说明 |
|---|---|
| `NEWS_SUB` | 如 `2026-10-26 收盘 ~ 10-27 06:19 · 影响开盘的关键事件` |
| `NEWS_COUNT` | 默认 `6`（凑不满 6 条时也写 6 条，弱条目合并到"其他动态"） |
| `NEWS1_T` … `NEWS6_T` | 标题，可用 `<span class="hl">关键数字</span>` 高亮 |
| `NEWS1_D` … `NEWS6_D` | 正文一句话，可用 `<b>` 重点 |

## 5. 图2 · 其他动态（固定 5 条）

`OTHER1` … `OTHER5`，每条 ≤ 34 字。

## 6. 图3 · 今日四指数预测（核心，先写这个）

| 键 | 示例 | 硬规则 |
|---|---|---|
| `{指数}_OPEN_LO` / `_OPEN_HI` | `3688` / `3702` | 开盘区间；宽度 ≤ 昨收 1% |
| `{指数}_OPEN_DIR` | `平开偏强` | 高开 / 平开 / 低开 + 程度，≤6 字 |
| `{指数}_CLOSE_LO` / `_CLOSE_HI` | `3680` / `3712` | 收盘区间；**宽度 ≤ 昨收 1%**（脚本强校验） |
| `{指数}_DAY_LO` / `_DAY_HI` | `3666` / `3720` | 全天波动；宽度 ≤ 1.5pct，且必须包住开盘与收盘区间 |
| `{指数}_PREV_CLOSE` | `3690.48` | 昨收（轨道刻度与涨幅基准） |
| `{指数}_SUP` | `3674/3666` | 支撑位（两个，斜杠分隔） |
| `{指数}_PRESS` | `3700~3720` | 压力位 |

> 脚本在渲染前会做三项硬校验，任一失败直接退出码 2 并列出是哪一项超限——**这是有意的**，宽区间等于没预测。

## 7. 图3 · 个股

| 键 | 说明 |
|---|---|
| `HK_FOCUS` / `HK_AVOID` | 港股关注 / 回避，`<b>名称</b>（代码 短理由）` |
| `SH_FOCUS` / `SH_AVOID` | 上证（含科创） |
| `GEM_FOCUS` / `GEM_AVOID` | 创业板 |

## 8. 今日日期

| 键 | 示例 |
|---|---|
| `TODAY_MD` | `10·27` |
| `TODAY_DATE` | `2026-10-27` |
| `TODAY_WEEK` | `周二` |

## 9. 总表专用（append_row.py 读取，可缺省）

| 键 | 说明 |
|---|---|
| `XLSX_PREV_RESULT` | 写在本行"上一交易日预测结果"列，如 `10-26：开盘3/4；收盘2/4；综合3/6` |
| `XLSX_BASIS` | 今日关键依据，3~5 个变量，短句 |
| `XLSX_STATUS` | 默认 `待验证` |

## 10. 文案长度红线（超了必溢出，脚本会拦）

- 图1 每条 `REV_NOTE` ≤ 34 全角字符；`EXTRA_NOTE` ≤ 40。
- 图2 每条 `NEWS_T` ≤ 18 字、`NEWS_D` ≤ 46 字。
- 图3 个股 `*_FOCUS` 每行 ≤ 3 只、总长 ≤ 40 字。
- 任何位置禁用 emoji（无字体，会显示成方块）。
