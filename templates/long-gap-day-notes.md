# 周一 / 节后首日（长间隔开盘）采集骨架 · 复制后改数字文字即可

> **用途（A46）**：周一、或节假日后首个交易日，距上一交易日隔了 2~3 天甚至更长。
> 「隔夜外围」不再是单纯一晚的美股，而是 **「最近一个美股交易日收盘」+「整个休市期间的消息面」** 两层；
> 且周末的机构「下周定调/七大机构预测」多是**按休市前最后一天盘中暴跌时点写的滞后推演**，
> 不能当成开盘前的最新定价依据。本骨架把这两层拆开，避免把上一日的低开基准惯性带到今天。
>
> **用法**：`cp templates/long-gap-day-notes.md work/{日期}/long-gap-day-notes.md`，
> 只改数字与文字；与 `market-data-notes.md`（A37 行情快照）并行使用，后者管点位，本文件管**时点与口径**。
> **触发条件**：`holidays.py` 显示的上一开盘日与今日之间 ≥2 个自然日（周末 / 长假 / 临时休市）。

```text
## 0. 间隔与交易日对齐（先做，别急着搜行情）
今日：{日期} {星期}，A股={开市/休市} 港股={开市/休市}
上一 A股/港股交易日：{日期}（{星期}）—— 这是 A36 定锚对象，也是图1 复盘对象
间隔：{N} 个自然日；其中美股交易日为：{列出休市期间实际开市的美东日期}
  ⚠️ 美股周末/假日休市，标题写「11月7日 美股收盘」的稿件，
     实际覆盖的是**美东 11-06 周五**收盘（北京时间 11-07 凌晨发稿）。
     务必用「美东日期」而非「中文发稿日期」对齐，否则会把周末不存在的行情当成隔夜。

## 1. 第 1 层：最近一个美股交易日收盘（决定开盘 gap 的主锚）
| 指数 | 收盘 | 涨跌幅 | 美东日期 |
|---|---:|---:|---|
| 道指 | | | |
| 标普500 | | | |
| 纳指 | | | |
| 费半 | | | |
- 中概金龙 ±X%（代表个股）；A50 夜盘 {点位}({±X%})；恒指夜期 / 中概 ADR
- 关键结构：反弹由「超跌芯片」还是「权重龙头」完成？是否冲高回落？（决定修复是否脆弱）
- 商品/利率/汇率：WTI、布油、现货金、美元指数、10Y 美债、离岸人民币

## 2. 第 2 层：整个休市期间消息面（决定 gap 的上修/下修）
- 国内政策（增量工具是否**实际落地**，从「文件」到「账户」）：
- 中美/地缘：
- 资金面（ETF 结募/建仓、回购增持、解禁、再融资抽水）：
- 交易所规则/指数编制修订：
- 本周日程（CPI/PPI、议息、财报、会谈）：

## 3. ⚠️ 滞后观点识别（本模板最核心的一条）
- 周末机构文（七大机构/十大机构/下周展望）成稿时点多为**上一交易日盘中或收盘前后**，
  其「低开高走 / 先抑后扬」等结论基于**当时的外围暴跌**，未必包含最后那个美股交易日的反弹。
- 判定：若「最后一个美股交易日」相对「上一 A股交易日」已由暴跌转反弹
  （如费半 -12.25% → +4.21%），则**机构共识的「低开」不可直接照抄**，
  应以「最后美股收盘 + A50 夜盘 + 中概」重新定价（本轮 11-09 即如此处理）。
- 机构观点只用于**结构与板块参考**，不用于**开盘方向**。

## 4. 低开/高开基准的退出条件（A43 的反向边界，别把惯性带过周末）
- A43「极端跳空不打折」只在**冲击发生的当日**成立；
  冲击已被上一交易日充分定价、且最后美股交易日转反弹时，
  **必须退出低开基准**，改按最新隔夜 + A34（政策托底上修）重新给方向。
- 检查四问：
  ① 上一 A股/港股交易日是否已把该冲击计入（全线收跌/收涨）？
  ② 最后一个美股交易日的方向是否反转？幅度多大？是否冲高回落？
  ③ A50 夜盘是否跟随恐慌？（+X% / -X%）
  ④ 国内是否有千亿级增量工具「实际买入」落地（A34 上修）？
- 结论：{平开偏强 / 温和高开 / 维持低开} —— 写明依据，不要沿用上一期标题。

## 5. 四指数分别定价（A28/A39）与 A36 定锚
- 昨收一律取**上一交易日实际收盘**（不取总表 N 列预估锚）：
  上证 { } / 创业板 { } / 恒指 { } / 恒科 { }
- 恒指/恒科不由 A股方向反推；各列「隔夜变量 → 本地符号」。
- 区间三项硬校验（收盘≤1%、全天≤1.5pct 且包住开与收、开盘≤1%）交给 build_charts.py。

## 6. 来源（≥2 源交叉，标注美东日期）
1. 次日早报（东财/陆家嘴/今日头条/金十）
2. 美股收盘通稿（中国基金报/中新经纬/财联社/格隆汇）
3. 周末消息面汇总（新浪证券/每经/华尔街见闻）
4. 机构定调（仅作结构参考，注明成稿时点）
5. 行情表精确开/收/高/低
```
